Question Bank

1. Download a backup first

Every question of every test, with answers and explanations, in one Excel file. Keep it safe: if a bulk import ever goes wrong you can fix things from this file. Importing this untouched file changes nothing.

Download question bank (Excel)

2. Import a whole question bank

One Excel sheet can hold many tests. Columns: Test Title (required), Test Number, Chapter, Subject, Q No, Question, Option A – D, Correct Answer (A/B/C/D), Marks, Negative Marks, Explanation.

  • Questions are matched to existing tests by Test Title and to existing questions by Q No. Matching questions are updated in place; nothing students have answered is deleted.
  • A title that doesn't exist yet creates a new test, saved as a draft — you publish it when you're ready.
  • If you re-order the options of a question students have already answered, their recorded answers move with the option text, and that test is re-graded.
  • A blank Explanation cell leaves the existing explanation untouched. Blank Marks / Negative Marks keep the current values.
  • You will see a preview of exactly what will change before anything is saved.
